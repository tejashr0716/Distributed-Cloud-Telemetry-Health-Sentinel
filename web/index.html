CloudSentinel

Static architecture showcase — no running backend on this page. No browser-generated number represents C++ performance, live cloud health, or consensus.

Synthetic multi-region telemetry prototype with a scalar C++ health-scoring library, PostgreSQL history, Redis windows and best-effort RabbitMQ alerts. No live AWS/Azure integration or explicit SIMD implementation.

Run the real interactive demonstration

Start your local stack, then open the local API-backed dashboard. The dashboard sends real requests to its own API and displays actual WebSocket events. It clearly reports unavailable dependencies.

docker compose up --build -d

Local demonstration only: the API has no authentication. Do not expose it publicly.

Evidence, not marketing numbers

Native CPU microbenchmarks and real HTTP workloads are measured separately. See the repository's reports/VALIDATION.md, raw samples and test logs. Results depend on hardware and workload; optional broker delivery, Docker builds and Spark are not verified by the supplied local run.
